# 🤖 Luttuxer MD — Telegram Bot

A personal Telegram bot built with Node.js, featuring AI chat, media tools, and automatic public media downloading.

## 🎬 Preview

[▶️ Watch Luttuxer MD Preview](https://files.catbox.moe/unbug6.mp4)

## ✨ Features

- 🤖 Gemini AI assistant
- 🎬 Automatic public Instagram media download
- ▶️ Automatic public YouTube media download
- 🎵 Automatic public TikTok media download
- 🐦 X / Twitter media support
- 📘 Facebook public media support
- 🖼️ Media tools
- 🎞️ Video to GIF
- 🎞️ Video to Sticker
- 🖼️ Image to Sticker
- ✂️ Video trimming
- 🏓 Ping / latency
- 💚 Bot alive status
- 👤 Owner information
- 📊 Bot status
- ⚡ Premium inline-button menu

## 🛠️ Tech Stack

- Node.js
- node-telegram-bot-api
- Google Gemini API
- yt-dlp
